# DOFBOT 数据采集台 v0.1.15 安装与使用

本软件面向 DOFBOT-PRO 与 Jetson Ubuntu 22.04 图形桌面，依赖 Python 3.10、PyQt5、OpenCV、FFmpeg 和厂家适配的 Arm_Lib。厂家 SDK 不随仓库提供，I2C 总线和相机兼容性须在各自设备上核对。

## 下载与安装

在仓库首页选择 Code → Download ZIP，将完整压缩包解压到机器人用户目录。私有仓库需维护者先授予 GitHub 账号访问权限，也可使用正常的 Git 认证克隆。不要将密钥写入源码或命令。

Ubuntu 下可按需安装通用依赖：

```bash
sudo apt update
sudo apt install python3-pyqt5 python3-opencv python3-numpy ffmpeg v4l-utils fonts-noto-cjk
```

配置厂家 Arm_Lib、smbus 和设备权限后，在图形桌面终端进入解压目录，验证并启动模拟模式：

```bash
/usr/bin/python3 verify-package.py
/usr/bin/python3 check-environment.py --demo
bash launch-demo.sh
```

真机使用前退出其他控制程序，在设备可靠支撑且现场有人监护时执行：

```bash
/usr/bin/python3 check-environment.py --real
bash launch-robot.sh
```

真机数据默认保存在 `~/dofbot-data/touch_collector`，日志在 `~/dofbot-data/reports`。可通过 `COLLECTOR_DATA_ROOT` 指定数据目录。会话标记与设备锁在 `software/` 下，不同副本无法互相排他；已有安装迁移时须先核对会话与数据状态，不能同时运行多个控制副本。

桌面快捷方式默认创建模拟入口，显式 `--real` 创建真机入口：

```bash
/usr/bin/python3 install-shortcut.py
/usr/bin/python3 install-shortcut.py --real
```

## 使用

1. 按界面步骤设置初始位置，并现场确认抱紧状态。松力时持续支撑机械臂，手避开夹爪和连杆。
2. 进入人工示教，记录并审核关节轨迹，然后保存。任务名称可在界面编辑。
3. 选择单摄或两台不同 RGB 相机，确认预览、帧率和工作范围。双摄按主机接收时间配对，不是硬件同步曝光。
4. 选择轨迹并确认路径，启动回放采集。回位时间根据运动范围和限速自动计算。夹爪 0～5° 补偿与 J3 ±3° 微调属于位置修正，不是力控制或重力补偿。
5. 审核视频和结果后保存。异常采集保留诊断，软件急停阻止后续软件指令，不能撤销已经发出的指令，也不能替代硬件急停。

每条数据包含图像、视频、时间戳、关节反馈和动作记录。视频按 10 fps 编码；精确时间分析使用 `samples.jsonl`。软件只采集 RGB，不记录深度或红外；输出需要转换后才能用于训练框架。

## 校验

执行 `python3 verify-package.py` 校验分发文件，在 `software/` 运行 `python3 -m unittest discover` 执行模拟硬件测试。验证记录见 `docs/测试与兼容性.md`。
