# 测试与兼容性

v0.1.15 GitHub 分发版基于现场维护的 v0.1.15，保留当前用户数据目录、软件目录设备锁和会话文件以及仅本机 HTTP 预览。分发版和现场版本的路径适配不同。

本次分发版在 Windows 完成 191 项模拟单元测试（Linux 文件锁测试跳过），在 Jetson Ubuntu 完成 191 项模拟单元测试。分发副本未启动真实机器人。

现场 v0.1.15 先前进行三轮真实双 RGB 相机与模拟机器人测试，每轮 401 帧。现场用户也保存过真实双摄采集。相机新鲜度问题具有间歇性，测试不能覆盖所有 USB 或调度状况。两台相机按主机接收时间配对，不代表曝光硬件同步。

实际使用依赖匹配的厂家 Arm_Lib、Jetson/I2C 与相机驱动。不同设备、线缆、供电和光照应另行验证。软件不提供碰撞检测、力控或重力补偿，软件急停不替代硬件急停。
